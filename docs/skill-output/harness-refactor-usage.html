설계된 흐름과 이번 실행

정상 경로에서는 감사 리포트가 스킬로 들어가고, 워크플로우 파일과 하네스 변경이 나온다. 이번 실행은 첫 화살표부터 성립하지 않았다.

claude/workflows/harness-refactor.js + 하네스 파일 변경
01

실행한 명령

인자를 받지 않는 범용 형식이다. 이번에도 인자 없이 그대로 실행했다.

/harness:harness-refactor        # 범용 형식 — 인자 없음
/harness:harness-refactor        # 이번에 실행한 명령
02

입력 — 세 순서의 탐색

Step 1 은 감사 리포트를 세 순서로 찾는다. 아래는 이번 실행에서 실제로 관측한 상태다.

1
.claude/reports/harness-legacy-check.md 디스크에 저장된 감사 리포트 파일
없음 · No such file or directory
2
현재 세션의 harness-legacy-check 출력 세션 안에서 방금 만들어진 리포트가 있는지
없음 · help 경로만 실행됨
3
둘 다 없음 진행에 필요한 입력이 확보되지 않음
가드 발동 → 중단
03

결과

입력이 없으므로 스킬은 Step 2 이후로 진행하지 않고 Step 1 에서 멈췄다. 사용자에게는 다음 안내가 그대로 출력됐다.

harness-legacy-check 결과가 없습니다. 먼저 /harness-legacy-check 를 실행해 주세요.

일어나지 않은 일

  • —claude/workflows/harness-refactor.js 는 생성되지 않았다.
  • —하네스 파일은 어느 것도 변경되지 않았다.
  • —Step 2 이후의 어떤 단계도 실행되지 않았다.
이것은 오류가 아니라 설계된 가드 경로다

감사 없이 하네스를 고치는 일을 막기 위한 장치다. 근거가 되는 리포트가 없는 상태에서 멈춘 것은 스킬이 자신의 안전 계약을 지킨 결과이며, 관측된 그대로가 정상 동작이다.

04

정상 경로로 가려면

리포트를 만든 뒤 다시 실행하는 두 단계
  1. /harness:harness-legacy-check 로 감사 리포트를 만든다 — 읽기 전용 감사이며 .claude/reports/harness-legacy-check.md 를 남긴다.
  2. /harness:harness-refactor 를 다시 실행한다 — Step 1 이 리포트를 찾아내면 이후 단계가 이어진다.
/harness:harness-legacy-check    # 1) 감사 리포트 생성
/harness:harness-refactor        # 2) 다시 실행 — 이번엔 입력이 있다
