7단계 파이프라인

인자를 파싱해 설치를 확인하고, 캐시에서 스킬을 열거한 뒤 멱등 스킵 게이트를 통과해야만 문서를 쓴다. 아래 노드를 누르면 해당 단계 설명이 열린다.

정상 흐름 멱등 스킵 게이트 조기 중단 분기

경계

언제 쓰고, 언제 안 쓰는가

이 스킬은 문서화만 한다. 설치 · 내장 스킬 · 커밋은 각각 다른 경로로 보낸다.

+사용
  • 설치한 플러그인이 어떤 스킬을 갖는지 한국어로 정리하고 싶다.
−사용 금지
  • 플러그인을 설치하고 싶다. 직접 /plugin install 을 실행한다.
  • 내장 스킬을 문서화하고 싶다. harness:dissect-builtin 으로 간다.
  • 문서를 커밋하고 싶다. 이 스킬은 커밋하지 않는다.

인터페이스

호출 형식

출력 파일 이름은 언제나 PLUGIN.md 다.

/harness:plugin-guide <plugin-name> [--force]
/harness:plugin-guide -h
인자 및 플래그
인자 / 플래그설명기본값필수
<plugin-name> <plugin>@<marketplace> 또는 <plugin> 단독 — 예
--force 문서가 이미 있어도 통째로 재생성 off 아니오
-h, --help references/help.md 를 그대로 출력하고 중단 — —
인자 누락 시 — Run /harness:plugin-guide -h for usage. 한 줄만 출력하고 멈춘다. 추측해서 진행하지 않는다.

상세

동작 단계

각 단계를 눌러 펼친다. 4단계는 문서가 이미 있으면 아무것도 쓰지 않고 멈추는 게이트다.

7단계 · 게이트 1개
1 인자 파싱 플러그인 이름과 마켓플레이스를 분리한다

@ 를 기준으로 PLUGIN 과 MARKETPLACE 를 나눈다. 마켓플레이스가 생략된 단독 이름도 유효한 입력이며, 이 경우 해석은 2단계가 담당한다.

2 설치 확인 부분 문자열 grep 금지 — 정확히 일치로만 매칭

claude/plugin/plugins.json 의 plugins 배열에 대해 PLUGIN@ 를 정확히 일치로 매칭한다.

부분 문자열 grep 은 쓰지 않는다 — skills 라는 플러그인이 example-skills@... 에 오탐되기 때문이다.

후보가 0개 / 1개 / 2개 이상 인 각각의 처리는 references/marketplace-resolution.md 에 있다.

3 캐시 탐색 + 스킬 열거 최고 버전 디렉터리만 남기고 SKILL.md 를 모은다

캐시 트리에서 스킬 정의 파일을 찾는다.

find "$CFG/plugins/cache/<MARKETPLACE>/<PLUGIN>" -maxdepth 4 -iname SKILL.md

버전 디렉터리가 여러 개면 sort -V 로 최고 버전만 남긴다. 결과가 0개면 스킬 없음, 문서화 대상 아님 으로 중단한다. 10개를 넘으면 경고 한 줄만 찍고 단일 파일로 계속 진행한다.

4 멱등 스킵gate 이미 있으면 아무것도 쓰지 않는다

대상 문서가 이미 있고 --force 가 없으면 이미 문서화됨 — 재생성하려면 --force 를 출력하고 멈춘다.

diff 나 병합은 하지 않는다. 재생성은 전부 다시 쓰거나(--force), 아무것도 하지 않거나 둘 중 하나다 — 부분 갱신이라는 중간 상태가 없다.

5 문서 작성 설치 방법 → 스킬 설명 → 사용법 예제

references/doc-template.md 의 3절 골격을 정확히 따른다: 설치 방법 → 스킬 설명 → 사용법 예제.

원본 SKILL.md 는 영어이므로 복붙이 아니라 요약해 한국어로 다시 쓴다.

6 인덱스 갱신 파일 끝이 아니라 Index 목록 안에 삽입

docs/guide/plugins/README.md 의 ## Index 목록 안, 마지막 - [...] 항목 뒤이자 다음 ## 헤더 앞에 한 줄을 삽입한다.

파일 끝에 무작정 붙이지 않는다. 이미 링크가 있으면 건너뛴다 — 인덱스 갱신도 멱등이다.

7 리포트 판정 · 쓴 파일 · 스킬 수 · 다음 단계

[OK] 판정, 쓴 파일과 건너뛴 파일, 문서화한 스킬 수, 그리고 다음 단계를 출력한다. 커밋은 사용자의 몫이므로 다음 단계 안내로만 남긴다.

제약

주의사항

스킬이 스스로 하지 않는 일들 — 넘어가지 않는 선이다.

설치하지 않는다

플러그인이 미설치면 사용자에게 알리고 멈춘다. 대신 설치해 주지 않는다.

커밋하지 않는다

커밋도 PR 도 열지 않는다. 스킬 스모크 테스트 역시 범위 밖이다.

한국어로 요약한다

생성 문서는 한국어다. 영어 원문 SKILL.md 를 복붙하지 않고 요약해 다시 쓴다.

이모지를 쓰지 않는다

생성 문서 어디에도 이모지를 넣지 않는다.
