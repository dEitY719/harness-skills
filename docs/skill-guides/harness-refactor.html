harness-refactor
감사 리포트 기반 low-risk 개선 적용

harness-legacy-check 감사 리포트를 읽어 low-risk 항목만 골라 claude/workflows/harness-refactor.js 를 새로 산출하고, 그 워크플로우를 실행해 실제 하네스 파일 변경을 만들어 낸다.

판단 기준

언제 쓰고 언제 안 쓰는가

이 스킬은 좁게 설계됐다. 아래 네 가지 상황 중 첫 번째에서만 쓴다. 나머지는 모두 다른 스킬로 넘어간다.

사용

harness:ai-context refactor
한 쌍의 설계

읽기 전용 감사 → 쓰기 적용

harness-legacy-check 가 읽기 전용인 반면 이 스킬은 쓰기다. 둘은 한 쌍으로 설계됐고, 리포트 파일이 둘 사이의 인터페이스다.

1단계 · 선행

harness-legacy-check

읽기 전용 (READ-ONLY)
  • 하네스 전체를 감사한다
  • 발견 항목을 리포트로 적는다
  • 어떤 파일도 바꾸지 않는다
  • 먼저 실행되지 않으면 다음 단계가 성립하지 않는다
인터페이스
▶
.claude/reports/
harness-legacy-check.md
▶
2단계 · 이 문서

harness-refactor

쓰기 (WRITE)
  • 리포트에서 low-risk 항목만 고른다
  • 워크플로우 파일을 산출한다
  • 실행해 실제 파일을 변경한다
  • 위험 항목은 적용하지 않고 보고만 한다
인터페이스

호출 형식

인자는 없다.

$ /harness:harness-refactor
$ /harness:harness-refactor -h

첫 인자가 -h / --help / help 이면 references/help.md 를 그대로 출력하고 중단한다. 그 외의 인자는 받지 않는다.

실행 흐름

동작 단계

각 단계를 눌러 세부 동작을 펼친다. 1단계는 가드, 4단계에서 처음으로 파일이 바뀐다.

1 감사 리포트 확인 가드 경로 클릭해서 펼치기

다음 순서로 찾는다.

  1. .claude/reports/harness-legacy-check.md 파일
  2. 현재 세션의 harness-legacy-check 출력
  3. 둘 다 없으면 "먼저 실행해 주세요" 안내 후 중단
2 low-risk 분류 판단 클릭해서 펼치기

references/classification-rules.md 기준으로 각 항목을 워크플로우에 포함할지 판단한다. 위험으로 분류된 항목은 여기서 걸러진다.

3 워크플로우 생성 산출 클릭해서 펼치기

claude/workflows/harness-refactor.js 를 새로 쓴다. 구조와 설계 원칙은 references/workflow-template.md 를 따른다. 이전 파일은 덮어쓰기되며, 이전 계획은 git log 에 보존된다.

4 워크플로우 실행 파일 변경 발생 클릭해서 펼치기

여기서 실제 하네스 파일이 바뀐다.

Workflow({ scriptPath: 'claude/workflows/harness-refactor.js' })
5 완료 보고 리포트 클릭해서 펼치기

다음 수치와 함께 [OK] 를 출력한다.

  • 변경 파일 수
  • 생성한 references/ 수
  • 아카이브 수
  • human review 필요 건수
전제와 한계

주의사항 / 제약

이 스킬을 돌리기 전에 합의돼 있어야 하는 것들.

⚠

실제로 하네스 파일을 변경한다

실행 전에 작업 트리가 깨끗한지 확인하고, 실행 후에는 git diff 로 검토한 뒤 커밋하는 것이 전제다.

◔

위험 항목은 자동 적용하지 않는다

위험하다고 분류된 항목은 Final Report 의 "Human Approval Required" 섹션에만 기록된다.

■

리포트가 없으면 아무것도 하지 않는다

감사 리포트가 없으면 멈춘다 — 이것이 정상 동작이다.

↻

이전 워크플로우는 병합하지 않는다

이전 harness-refactor.js 는 통째로 덮어쓴다. 과거 계획은 git 히스토리에서만 확인한다.

⚙

Claude Code 의 Workflow 도구에 의존

다른 하네스에서는 references/*-tools.md 의 대체 경로를 따른다.
